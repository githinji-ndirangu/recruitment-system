# Safari Global – International Recruitment Management System (frontend mockup)
```
npm install
npm run dev
```
React + Vite + Tailwind + Lucide + Recharts. Data is seeded locally and persisted in localStorage (key `irms.v1`). Use profile menu → "Reset demo data" to restore the seed.
Vacancy logic: Remaining = Total − allocated (Employer Approved, Processing, Ready for Deployment, Deployed). "Matched/Applied/Shortlisted/Interview" never count as allocated.
